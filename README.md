## About this entry

The line is Monday in miniature, which is exactly the joke the
bounty asks for. It opens with the verdict itself, "Monday again.",
so the reader gets the point before the punchline even arrives. Then
it stacks three tiny grievances in a row: the alarm clock has filed
for overtime, the coffee has filed for hazard pay, and the motivation
is still on annual leave. That is Monday morning in one sentence, a
day where even the objects around you are demanding compensation and
the one thing you need most has taken the day off. The line is a
single sentence, it needs no explanation, and it stays well inside
the one hundred and forty character cap. The program holds the line,
checks it against that cap, and writes it to /output/entry.txt
exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
